# Сайт музея «Дом коллекционера» × галерея «Коносьеръ»

Исходники страниц сайта [dom-kollekcionera.ru](https://dom-kollekcionera.ru/).

- `site/` — страницы сайта (`.html`), `sitemap.xml`, `robots.txt` и новые картинки.
  Хостинг reg.ru раз в 15 минут сам скачивает эту папку и обновляет сайт
  (задача в «Планировщике CRON» панели ISPmanager). На сервер попадают только файлы
  `.html .xml .txt .jpg .jpeg .png .webp`; PHP и настройки сервера не обновляются.
- Старые картинки, стили (`assets/site.css`) и скрипты лежат только на сервере — в репозитории их нет, и они не меняются.
- `agent/` — инструменты еженедельного агента сайта и журнал его работы (`agent/journal.md`).

Откатить любое изменение: на GitHub откройте коммит → «Revert», через 15 минут сайт вернётся к прежней версии.
Остановить автообновление: удалите задачу в «Планировщике CRON» на reg.ru.
